# Клуб четырёх коней

Адаптивный промо-сайт «Международного васюкинского турнира» - демонстрация ключевых мероприятий, этапов преобразования города и списка участников.  
Проект свёрстан по методологии БЭМ, оптимизирован по производительности и доступности.

## Стек технологий

| Технология | Назначение |
|------------|------------|
| HTML5 | Семантическая разметка |
| SCSS → CSS3 | Модульные стили, минификация, автопрефикс |
| JavaScript (ES6) | Слайдеры, навигация, бегущие строки, адаптивные переносы |
| БЭМ | Соглашение об именовании классов |
| Git | Контроль версий |
